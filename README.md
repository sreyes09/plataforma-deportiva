# Vyrox

## Descripcion general del sistema
Vyrox es una plataforma web para registrar, visualizar y analizar el rendimiento deportivo individual. El sistema permite que cada deportista lleve control de sus estadisticas personales, mientras que los entrenadores pueden vincular cuentas reales de atletas, asignar metas, sesiones, competencias y observaciones, y revisar el avance de cada uno desde un tablero central.

## Objetivo del proyecto
El objetivo principal es apoyar el seguimiento del progreso personal en el deporte, promoviendo la cultura del esfuerzo y la mejora continua mediante indicadores claros, historicos visuales y una relacion directa entre entrenador y deportista.

## Tecnologias utilizadas
- Frontend: React + Vite + Tailwind CSS + Recharts
- Backend: Node.js + Express
- Base de datos: MongoDB Atlas + Mongoose
- Seguridad: JWT, bcryptjs, verificación de dos pasos con código temporal y envío por SMTP

## Instrucciones para ejecutar el sistema
1. Instalar dependencias en `backend` y `frontend`.
2. Configurar variables de entorno del backend.
3. Levantar primero el backend en `http://localhost:5000`.
4. Levantar luego el frontend en `http://localhost:5173`.
5. Registrar usuarios y acceder con login de dos pasos.
