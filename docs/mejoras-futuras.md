# Propuesta de mejoras futuras

## Funcionalidades pendientes
- Restablecimiento de contrasena por correo.
- Administracion central para el rol administrador.
- Notificaciones en tiempo real para metas o sesiones nuevas.
- Exportacion de reportes en PDF o Excel.

## Posibles optimizaciones
- Dividir el frontend en bundles mas pequenos.
- Implementar paginacion o carga perezosa para listados extensos.
- Separar metas, sesiones y competencias en colecciones dedicadas si el volumen crece.
- Agregar cache de consultas frecuentes.

## Ideas de evolucion del sistema
- Integracion con correo real o app autenticadora para el segundo factor.
- Integracion con wearables o dispositivos deportivos.
- Ranking avanzado por disciplina y categoria.
- Indicadores predictivos de rendimiento y riesgo de bajo cumplimiento.
